## 🧠 Learning Journey: FreeCodeCamp - Responsive Web Design

This project is part of the **FreeCodeCamp Full Stack Developer Certification**, specifically under the **Responsive Web Design** section.

FreeCodeCamp organizes its learning path through hands-on coding challenges and real projects. Each section builds your skills step-by-step, and this particular project — the **Tribute Page** — is the first project that helps solidify basic **HTML** and **CSS** knowledge in a practical way.

📝 What I learned here:
- How to structure an HTML document from top to bottom
- The importance of properly closing all tags (like `<html>`, which I initially forgot)
- How to create semantic sections like `<header>`, `<main>`, and `<footer>`
